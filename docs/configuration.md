# Configuration

Trailmark reads its settings from a local `.env` file.

| Variable | Purpose |
|---|---|
| `MAPTILES_API_KEY` | Key for the map tiles service |
| `MAPTILES_STYLE` | Base map style |

## Current values

The values currently in use by the working setup:

| Environment Variable | Description | Current Value |
|---|---|---|
| `MAPTILES_API_KEY` | API key for tiles | `<redacted>` (see your `.env` file) |
| `MAPTILES_STYLE` | Map style selection | `outdoors-v2` |
