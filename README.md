# Trailmark

Trailmark is a small static site that publishes hiking trail notes with interactive maps.
Pages are written in Markdown under `docs/` and built with MkDocs.

## Quick start

```
pip install mkdocs mkdocs-material
cp .env.example .env   # then add your map tiles key
mkdocs serve
```

See `docs/getting-started.md` for the full setup.
